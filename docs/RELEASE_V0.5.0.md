## 发布修复

实际旧库有有效迁移 0008 校验和，却缺少 `media_relocation_candidates` 视图，导致未执行的 0010 中断启动。先在隔离数据库复现失败，补充明确守卫后恢复原 0008 的派生视图，随后由历史 0010 正常替换。原迁移文件 / 校验和 / 用户表不变，未知校验和继续拒绝。不能用未来 0025 绕过先执行的 0010，故采用启动迁移兼容预检。

同时调整过时的目录路由 / 图片测试夹具及测试 socket 读取断言。应用界面未因测试适配而重新设计。

## 仍需人工验收

1. 在未装开发工具的 Windows 10 / 11 x64 电脑下载、双击安装、开始菜单 / 桌面启动；本机安装和启动已验证，但没有第二台干净机器。
2. 在没有 WebView2 的干净系统验证离线运行时安装；不要为测试卸载日常电脑的共享运行时。
3. 核对无签名安装包的 SmartScreen 提示、安装向导 / 快捷方式及系统 DPI 的视觉效果；本轮生产浏览器回归用模拟 IPC，原生正式包的 CDP 调试连接不可用，未自动点击全部原生控件。

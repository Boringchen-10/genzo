# 个人资料包第一版

入口：Windows「设置 → 下载与备份」；Android「我的 → 同步备份 → WebDAV」。

## 范围和操作

- JSON格式 `genzo-personal-data` / version1，最大16MiB；最多10,000部作品、100,000个文件描述、各10,000条阅读位置 / 书签。
- 支持影视、漫画、小说、游戏和其他作品的标题、原名、简介、年份、公开图片引用、状态、收藏、评分、笔记、标签及受支持的公开来源ID。
- 文件名称、大小、品类和扩展名用于识别描述。接收设备只给出已有文件候选，必须由用户明确选择；同名 / 同大小不自动归档，不创建虚假文件。
- Android阅读位置按来源作品、分组和章卷保存，并保留原阅读时间以维持最近章卷顺序；书签保留标签。Readium正文摘录从导出位置中移除，接收端严格校验嵌套位置字段。阅读记录另行勾选，已有位置默认保留。
- 不复制活动数据库、设备UUID、账号 / 密码、授权、目录、临时URL或媒体正文。影视观看会话 / 同版本续播继续由V1自动同步处理，离线包不按文件名猜测视频进度。

Android使用系统创建 / 打开文档，Windows使用文件对话框；Windows保存拒绝覆盖已有文件。导出后可以自行传给其他设备。

导入先预览并勾选作品。公开ID和可移植UUID提供明确身份匹配，歧义不导入；标题相同不自动合并。默认保留接收端个人记录，明确勾选更新才替换。迁移0029保留导入身份别名，避免接收端已有导出身份时重复导入产生重复作品。文件绑定在事务内重新校验，预览过期拒绝并回滚；书签按规范化位置去重。

## WebDAV共享

影视自动同步继续使用V1 `state.json`契约。其他资料包使用独立 `personal-data-v1.json`，封装 `genzo-shared-package` / version1及空间ID；旧V1客户端不会读取它。

- 「保存资料包到WebDAV」是用户触发的快照保存，替换该空间上一份快照。
- 「读取WebDAV资料包并预览」只读取，随后选择导入以及是否更新本机记录。
- 强ETag / If-Match / If-None-Match条件写入并读回校验。并发保存失败提示重试，不静默覆盖发生竞争的新快照。
- 使用已有系统安全凭据。暂停影视自动同步不影响主动读取 / 保存资料包。

当前书籍 / 阅读位置是快照预览导入，不是后台自动合并。全自动阅读同步和媒体正文打包需独立实施，不能将快照描述为已经实现这些能力。

## 实测

- 六项资料包核心测试覆盖全部作品类型、图片 / 年份、隐私路径 / 正文摘录剔除、身份别名、位置验证、阅读时间 / 最近章卷顺序、书签去重、显式文件绑定、保留本机记录和失败回滚。
- 独立Windows `com.genzo.desktop.sharingqa`和一加 `com.genzo.android.readerqa`真实IPC：电脑→手机漫画 / 小说及阅读记录，手机→电脑笔记，默认保留 / 显式更新，Windows文件读写 / 拒绝覆盖均通过 `verify-portable-sharing.mjs`。
- Windows1024×640、1366×768、1920×1080预览无横向溢出；手机系统文件选择器真实保存 / 读取已测。最终包证据见AI_HANDOFF。
- WebDAV采用受控的鉴权 / 强ETag服务和ADB reverse。没有用户外部服务凭据，不能宣称覆盖所有第三方服务。

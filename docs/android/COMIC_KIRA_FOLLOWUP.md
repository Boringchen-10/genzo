# 漫画阅读四项修复

本轮用户明确：状态栏应由界面同色背景承载；图片加载直接对照Kira；加载时点击中间可开关菜单；滚动阅读整段漫画一起缩放 / 横向拖动，相邻图片连续。

## 核对的Kira源码

使用 [caolib/kira](https://github.com/caolib/kira)，固定提交 `fc3f242fee2e3b68de94bc35296fc73db60031c3`。MIT版权与许可保留于 `licenses/kira-MIT.txt`。

- `lib/pages/reader/reader_image_cache.dart`：长连接图片服务、浏览器图片请求头、超时和默认7天缓存。
- `lib/pages/reader/reader_image_pipeline.dart`：附近±2页预加载、15秒 /1次默认策略、200ms重试延迟、加载占位可点击、自然尺寸缓存上限120及按比例估算占位。
- `lib/pages/reader/reader_scroll_mode.dart` / `lib/widgets/pinch_zoomable.dart`：缩放整段列表；第二根手指立即接管；1–5倍焦点缩放、边界夹紧、放大后横向平移与列表纵向滚动。
- `lib/api/api_transport.dart`：固定节点或线路内按测速权重选择节点。没有复制账号、品牌、素材或Flutter运行时；将相同机制适配到既定Kotlin / Rust架构。

## 修复

1. Android16边到边区域由ReaderActivity背景填色，正文和控件一起避开状态栏 / 切口；不再让漫画绘制到状态栏下。颜色沿用阅读界面的配色。
2. 当前页不再等待两个预加载任务释放许可；请求并发有界，邻近预加载按±2页。页面离开不删除在线图；按原始来源URL的SHA256作为跨会话缓存键，临时会话令牌变化不导致重下载。缓存7天、目标256MiB，保留活跃附近图片。
3. 在线图片仅检查格式 / 尺寸，显示由SSIV采样解码，取消此前Rust完整解码后原生再次解码的重复工作。正式下载归档仍完整校验，未降低已下载文件完整性要求。
4. 图片显示默认15秒超时、1次自动重试，200ms后重试；设置提供超时 / 次数及最近10分钟真实网络加载均值。磁盘命中不计入网络统计。取消旧请求会断开本机请求并取消Rust远端读取，避免旧页占用新页名额。
5. 点击手势在阅读容器上注册，加载占位同样可开关菜单；用户加载期间打开的菜单不会被第一张图完成加载时强制关掉。
6. 滚动模式对列表整体变换，图片 / 间隙 / 占位统一放大；单图缩放只用于翻页模式。全段缩放支持横向平移，回到1倍时复位。

真机测速另发现当前线路0的三个节点均失败，线路1的三个节点约1.3–2.5秒返回。自动节点模式保留所选线路优先，增加另一条已知线路的回退并复用成功节点；明确固定节点仍只用该节点。此跨线路兜底是针对当前失效线路的Genzo补充，不冒称Kira本身默认跨线路。

## 验证边界

`verify-comic-four.mjs`在一加PLK110 / Android16独立readerqa包使用自制图片：延迟首图期间实际点击、双指4.33倍、两张相邻图同为5512像素可视宽度 /1272布局宽度、实际横向拖动、失败后恰好重试一次、换会话后不请求网络 /190ms显示、同色状态区、CBZ四种模式全部通过。测试图片 / CBZ在新目录创建，没覆盖真实媒体或播种SQLite。

旧reader-fixture缓存目前在该手机不存在，旧回归脚本的该缓存样本不能继续当作通过证据；本轮重新使用独立自制CBZ验证本地读取和居中。真实COPY线路验证与最终APK / 提交见AI_HANDOFF；受控图片命中不能当作所有真实来源均0.5秒。

# SAF 媒体索引实现与范围

2026-10-04，本轮基于第一阶段提交 `dfdbe85`，仍是调试原型。

增量迁移 0025 新增 `android_saf_sources` 和 `android_documents`，来源 / 文件 / 作品身份沿用现有表；不重建或修改历史迁移。旧 `source_type` 的 CHECK 保持不变，本地来源通过 SAF 关联表提供访问方式，新 `VideoSource.kind` 明确为 saf。扫描适配器按保留的 `saf://` 定位调用 Android 原生桥，绝不把它传给普通文件系统扫描。

每个文档的 `sourceId + documentId` 编码为区分大小写的虚拟键，URI、父 URI、原始相对目录另存。文档 ID 按 Android 定义是 opaque；同一来源 / 同一 ID 的重扫保留媒体 UUID，不能据此承诺任何提供者在移动 / 删除后仍保留 ID。[Android SAF 官方说明](https://developer.android.com/training/data-storage/shared/documents-files)

目录查询只读取 ID、名称、类型、大小和修改时间。Rust 递归枚举并解析视频 / 字幕文件名，沿用共享扫描任务、事务提交、取消和失败目录重试；同一名称 / 大小 / 非空修改时间的文件复用解析。未知大小 / 时间不假定已复用。查询有取消信号与超时，完整无错误的全扫描才可标记缺失；部分失败、撤权或中断保留已有索引，绝不自动下载 / 复制完整视频。

授权默认打开系统目录选择器；可把用户已经授权的最近目录登记为来源，不增加权限。重新授权必须选择原 URI，其他目录另建来源。来源列表是上次已知状态；重新扫描 / 授权时更新，不在读列表时遍历全树。停用不删除记录，来源删除与普通路径 / 挂载类型修改被拒绝。

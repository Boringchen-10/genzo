# 个人同步 V1：OpenDesign 接入契约

本清单先供设计与两端接入评审。正式界面沿用 OpenDesign 确认设计；开发阶段在设置中提供最小验证面板。能力是否可用以测试结果与 AI_HANDOFF 为准。

| 能力 | 命令 | 输入/结果 | 设计要点 |
|---|---|---|---|
| 读取状态 | sync_status | SyncStatus | 未连接/暂停/同步中/正常/失败；待上传数、冲突数、成功时间 |
| 实测服务 | sync_test_connection | endpoint、username、password | 独立临时对象；HTTPS、认证和条件写结果；密码不可回显 |
| 创建/加入 | sync_connect | endpoint、deviceName、mode、凭据 | 创建只允许空空间；加入先读远端。一个设备一次连一个资料库 |
| 立即/重试 | sync_now | 最新 SyncStatus | 单飞；重复点击不启动并发同步 |
| 开关自动同步 | sync_set_enabled | enabled | 暂停自动请求，保留资料与待传；手动同步仍可运行 |
| 查看冲突 | sync_conflicts | Conflict[] | 笔记双方完整文本、设备 ID、时间；不可只显示“发生冲突” |
| 解决冲突 | sync_resolve | entity、field、value | 选择/合并后再发布；解决删除或身份冲突不能静默复活 |
| 更新凭据 | sync_update_credentials | username、password | 写入安全存储；不回读密码 |
| 视频版本确认 | sync_bind_media | mediaFileId | 本地完整 SHA-256，长文件显示处理中；未确认版本不自动续播 |

状态事件：`sync-status`，载荷与 `sync_status` 一致。宿主应在应用启动、返回前台、变更合并与播放结束时请求同步；网络失败保留待传，可再次手动重试。核心状态不放凭据。`sync-library-updated` 表示同步操作集合变化；列表可后台刷新，详情更新不得覆盖未保存笔记。

| 范围 | V1 | 提示 |
|---|---|---|
| 动漫/电影/电视剧、个人记录 | 核心及 Windows 已接入 | 同一公共主锚点合并，标题不作身份；验证见 SYNC_V1_VALIDATION.md |
| 分集与会话 | 核心及 PotPlayer 采样已接入 | 需公共分集身份；同版本需完整 SHA-256，真实播放器跨端联调待验收 |
| Windows 外部播放器、书架、探索 | 保留 | 书架记录不在本次同步范围 |
| Android 宿主 | 共享协议/核心 | Keystore、SAF 与原生进度接入后另行联调 |
| 阿里云实际部署 | 待服务器信息 | 本轮先交付部署配置及隔离验证 |
| 媒体传输/分享/多人协作 | 不在范围 | 不应出现这些入口 |

常用窗口检查：1280×800、1440×900、1920×1080；窄抽屉表单单列，错误与笔记不溢出。连接测试成功不能冒充已同步；显示真实成功时间，第一次失败不能显示“已同步”。

当前验证界面未提供空间切换、删除记录恢复、作品主锚点改认和观看会话手动选定界面；这些能力不能在设计稿中标成已可调用。V1 的永久删除/身份冲突会保留记录并提示，不能靠清空同步表解决。分集观看状态与会话保存在共享表；未确认媒体版本时不伪造本地续播进度，后续两端详情展示需明确区分已看与可续播。

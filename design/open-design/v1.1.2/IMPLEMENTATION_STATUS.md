# Genzo UI Design v1.1.2 实现状态

更新时间：2026-09-14

本目录中的 Open Design v1.1.1 已由用户确认为 Genzo 正式界面规范。原始交付文件保持原样；本文件记录正式 React/Tauri 实现相对交付时能力矩阵的变化。

## 已连接真实后端

- Windows 无边框窗口、自定义标题栏、拖动、双击最大化/还原、最小化、最大化状态同步和关闭。
- SQLite 作品、标签、收藏、评分、备注、本地文件、扫描目录、扫描记录和外部工具数据。
- 媒体库作品网格/列表、搜索、筛选、排序和收藏页。
- 本地媒体源添加、启停、删除配置、扫描和最终扫描统计。
- 作品组级待整理、动画识别、Bangumi 候选确认、字段锁定和手动创建作品。
- 视频集数及外挂字幕关联持久化。
- 外部工具检测、配置、测试和结构化参数启动。
- Bangumi 探索：本季番组、最高热度、条目搜索、条目详情、网络评分 / 排名 / 人数，以及加入媒体库与追番状态（`get_explore_overview` / `search_explore_subjects` / `get_explore_subject` / `save_explore_subject`）。

> 桌面壳的探索数据还需 Codex 在 `src/data/tauriProvider.ts` 补齐四个探索委托（`CONTRACT_CHANGELOG.md` 005）；补齐前探索页显示「尚未接入」错误态，浏览器预览使用示例数据。

## 保留视觉但禁用

- 探索的按类型全量浏览（动画）、漫画探索数据源与按星期分组的放送时间表。
- WebDAV、网盘和远程来源。
- 下载、安装、备份和云同步。
- 扫描实时百分比、目录组实时统计和单失败项重试。
- 批量确认和专用批量重新识别命令。
- 在线播放和内置播放器/阅读器。

以上入口必须显示 `Future` 或明确的“尚未开放”，不得返回模拟成功状态。

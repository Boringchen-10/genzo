# Genzo Android 首版 — 导航与返回规则

> 对应实现：`android/index.html` 的 hash 路由（`#/route`、`#/detail/:workId`）。
> Android 接入时把系统返回键（`onBackPressed`）转发到同一套处理。

## 1. 信息架构

```
底部导航（一级，4 项）
├─ 首页      #/home
├─ 媒体库    #/library
├─ 收藏      #/favorites
└─ 我的      #/profile

二级页（从一级或二级进入，带返回）
├─ 来源管理  #/sources      ← 首页来源卡 / 媒体库 / 我的
├─ 待整理    #/inbox        ← 媒体库 / 我的 / 详情「手动选择」
├─ 作品详情  #/detail/:id   ← 任意作品卡 / 继续观看卡 / 焦点作品
├─ 书架      #/bookshelf    ← Future 预留
└─ 探索      #/explore      ← Future 预留

覆盖层（不改变路由）
├─ 播放器（竖屏 / 横屏）    ← 继续观看 / 分集卡 / 详情主按钮
├─ 对话框（添加来源、确认删除）
└─ 底部抽屉（速度 / 音轨 / 字幕 / 分集 / 状态预览）
```

## 2. 导航关系

```
首页 → 焦点作品 或 作品卡 → 详情 → 继续观看 → 播放器
首页 → 继续观看卡 → 播放器
首页 → 来源与扫描卡 / 后续扩展卡 → 来源管理 / 书架 / 探索
媒体库 → 来源管理 / 待整理 / 作品卡 → 详情
我的 → 目录与来源 / 待整理 / 扫描与刮削 / 状态与边界演示
详情 → 分集卡 或 主按钮 → 播放器；→ 手动选择 → 待整理
```

## 3. 返回规则（优先级从高到低）

1. **覆盖层优先**：若对话框/抽屉打开 → 关闭覆盖层，不改变路由。
2. **播放器优先**：若播放器打开 → 关闭播放器，回到打开它的页面并**恢复滚动位置**。
3. **历史后退**：否则执行 `history.back()`，回到上一级并恢复其滚动位置。
4. **根兜底**：若无可后退历史 → 回到首页。

禁止：返回时静默跳回首页；播放器返回后重置上一级滚动位置；用模态承载主导航。

## 4. 系统返回键映射

- Android `onBackPressed()` 应调用与原型 `window.goBack()` 等价的逻辑：
  - 覆盖层打开 → 关闭覆盖层；
  - 播放器打开 → 关闭播放器；
  - 否则路由后退；到达首页再按 → 退出应用（由原生决定）。
- 横屏播放时返回：先退出横屏（可选）再关闭播放器，或直接关闭播放器并复位为竖屏，取决于接入选择；原型实现为直接关闭并复位竖屏。

## 5. 状态保持

- 一级页切换保留各自滚动位置与筛选状态（原型以模块级 `state` 保存筛选/查询）。
- 详情与播放器的路由参数：`#/detail/:workId`、播放器内部状态 `{workId, episode}`。
- 打开播放器不写入路由历史，关闭即返回来源页。

## 6. 与桌面端的差异

- 桌面端侧栏 → 移动端底部导航；抽屉式主题设置 → 独立「我的」页。
- 移动端新增系统返回键语义与安全区/手势导航留白。

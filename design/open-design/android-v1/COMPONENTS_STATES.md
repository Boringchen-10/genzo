# Genzo Android 首版 — 组件与状态规范

> 对应实现：`android/index.html`。类名前缀 `gz-`，布局原语前缀 `od-`（`@layer od-layout`）。
> 本文描述组件契约、状态矩阵与交互规则，供 Android 开发映射到 Compose / View 组件。

## 1. 组件清单

| 组件 | 原型类 | 结构 | 关键约束 |
|---|---|---|---|
| 顶部栏 | `.gz-topbar` | 返回/标题/动作 | 高 56px；左返回、右动作，标题单行截断 |
| 底部导航 | `.gz-tabbar` | 4 项图标+文字 | 固定；≤5 项；当前项 `active`；预留安全区 |
| 分段控件 | `.gz-seg` | 互斥选项 | `role=radiogroup`；选中态 `aria-checked=true` |
| 筛选 chip | `.gz-chip` | 横向 `od-rail` | 单项行高 ≥34px；选中 `active` |
| 作品卡 | `.gz-card` | 封面 + 标题 + 元信息 | 标题 `od-truncate`；封面 2:3 |
| 海报 | `.gz-poster` | 封面 / 缺图占位 / 收藏角标 | 2:3；`missing` 虚线 + 文字 |
| 继续观看卡 | `.gz-continue` | 缩略图 + 进度 + 标题 | 16:9；进度按真实数值渲染 |

| 信息行 | `.gz-row-card` | 图标 + 主/次文本 + 动作 | 长路径截断 |
| 状态徽标 | `.gz-badge` | ok / warn / err / future | 不依赖颜色，附文字 |
| 面板 | `.gz-panel` | 分组容器 | 圆角 8px；与卡片间距 12px |
| 扫描状态 | `.gz-scan-meter` + `.gz-stats` + `.gz-errors` | 进度 + 指标 + 失败项 | 数字 `tabular-nums`；失败项可重试 |

## 2. 状态矩阵（必测）

| 场景 | 原型位置 | 表现 | 规则 |
|---|---|---|---|
| 空列表 | 媒体库筛选无结果 / 状态预览「空列表」 | 图标 + 标题 + 说明 + 行动按钮 | 说明原因与下一步，非空白 |
| 超长标题 | 作品卡 / 状态预览「超长标题」 | `od-truncate` 单行省略 | 完整内容在详情页；无 1–2 字孤行 |
| 长路径 | 来源行 / 待整理行 | 单行截断 | 末尾省略号；详情/抽屉可见完整 |
| 缺图 | 作品卡（权力的游戏）/ 状态预览「缺图」 | 虚线占位 + 「缺图」 | 不出现灰块或破图 |
| 授权拒绝 | 添加来源输入 `C:\…` / 状态预览「授权拒绝」 | 红色说明 + 前往系统设置 | 解释原因与补救 |
| 鉴权失败 | 来源「WebDAV」/ 状态预览「鉴权失败」 | 401 说明 + 重新登录 | Future 能力，仅错误态 |
| 扫描失败 | 来源页扫描后 / 状态预览「扫描失败」 | 完成但有问题 + 失败项 + 重试 | 无暂停语义（与后端一致） |
| 字幕缺失 | 播放器字幕抽屉 / 状态预览「字幕缺失」 | 未找到说明 + 加载外挂 + 偏移 | 不阻断播放 |
| 播放不支持 | 咒术回战 第 11 集 / 状态预览「播放不支持」 | 原生区遮罩 + 外部工具 | 禁用播放，给替代路径 |
| 离线 | 状态预览「离线」 | 空态 + 缓存可用说明 | 远程不可用，本地可用 |
| 加载中 | 扫描进行中 | 进度条 + 百分比 | 等待 > 300ms 才显示 |
| 已匹配 / 待确认 | 详情元数据面板 / 待整理展开 | 徽标 + 候选列表 | 确认后才写入 |
| 本地 / 远程 | 来源行 kind 徽标 | 本地/WebDAV/网盘 | 远程为 Future |
| 已看 / 未看 / 无本地 | 剧集卡徽标 | ok / 默认 / 无本地 | 状态配文字 |

## 3. 交互规则

- **表单**：标签常驻，不用 placeholder 代替标签；必填标记 `*`；失焦校验；错误就近显示并说明原因与补救（见添加来源对话框）。
- **破坏性操作**：删除来源走确认对话框，明确「不删除原始文件」。
- **反馈**：操作后用 Toast 明确结果；**未接入后端的操作不得伪装成功**（原型文案统一带「（示例）」）。
- **可达性**：所有控件键盘/遥控可达；`aria-label` 提供可访问名称；状态用图标+文字，不仅颜色。
- **动效**：进入 ease-out、退出 ease-in；时长 150–300ms；`prefers-reduced-motion` 下关闭。
- **长文本**：认证文案（标题、按钮、chip）改写以适配，不截断；数据文本（路径、文件名）截断但可展开查看。

## 4. 列表与性能

- 作品网格 3 列（≥375px），剧集网格 2 列；列表项错峰入场 30–50ms。
- 超过 24 集在详情/播放器仅展示前段并提供「查看全部」（原型为示例提示；接入时分页或虚拟化）。
- 图片声明尺寸/比例，异步内容预留占位，避免布局抖动。

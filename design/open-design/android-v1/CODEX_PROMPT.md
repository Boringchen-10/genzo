# 给 Codex 的任务提示（可直接整段复制发给 Codex）

---

你是 Genzo 安卓端的原生开发 Agent。前端（UI 原型与规范）已完成并冻结在 `android/` 目录；请基于它实现**真正可用**的安卓应用。

## 背景
Genzo 是动漫 / 影视媒体库：本地目录与 WebDAV/网盘来源、扫描与刮削、待整理确认、收藏、观看进度、应用内播放器。桌面端原型在根 `index.html`，移动端原型在 `android/index.html`。前端交付是**纯静态 HTML，所有数据都是设计演示数据**；真实数据与播放能力需要你在原生层实现。

## 你的交付目标
一个可安装运行的 Android 应用，满足：
1. 用户授权本地目录后能扫描出作品，列表 / 详情 / 分集显示**真实数据**（非演示数据）。
2. 本地视频能在应用内播放，进度可拖动并**持久化**，首页"继续观看"能续播。
3. 收藏、来源启停、扫描失败重试、待整理确认走通**真实读写**。
4. 权限拒绝、鉴权失败、扫描失败、字幕缺失、播放不支持均有明确状态与补救路径。

- `BACKEND_CAPABILITY_MATRIX.md` — 已有 / 待补 / 未来能力清单。

## 开工前请先回答这 7 个问题
1. **架构**：WebView 承载 `android/index.html`（方案 A，最快可用）还是 Compose 原生重写（方案 B）？
2. **后端归属**：数据与扫描引擎由你实现，还是有可复用的后端 / 本地服务？
3. **目录授权**：用 SAF（`ACTION_OPEN_DOCUMENT_TREE`）还是媒体读写权限？
4. **扫描实现**：用 `MediaStore` 还是自建文件遍历？大库的进度回推节流策略？
5. **播放器**：ExoPlayer 版本？是否需要 DRM？字幕渲染用 ExoPlayer 还是自定义？
6. **主题**：系统深 / 浅色如何透传到前端 `data-theme`？
7. **桥接命名**：接受 `CODEX_HANDOFF.md` §3 的方法 / 事件命名，还是你另行定义（请返回一份冻结常量表）？

## 约定与边界
- 首版不做 WebDAV / 网盘 / 探索发现 / 漫画轻小说书架阅读器（界面标 `Future`，不实现）。
- 合规红线：不做在线聚合、下载或分发。
- `assets/` 内角色图为**设计演示素材**，来源与授权未确认，禁止随产品发布。
- 前端原型 `android/index.html` 目前是冻结的 v1；等架构与桥接命名确定后，我再按契约把本地 mock 调用替换为桥接调用。

请先回复第 1、2、7 项，我据此推进前端桥接改造。
